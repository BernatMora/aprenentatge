📚 Curs d'harmonia avançat

De l'anàlisi funcional al segle XX, en quatre blocs. Fet amb el teu material (els teus llibres i els teus 20 temes) i amb correcció personal. Pensat per fer amb el mòbil ✓ i sense escriure ✓: llegeixes, toques i m'envies àudios.
📐 Bloc A · Anàlisi (4 lliçons)
L'anàlisi funcional ✓, els dominants secundaris ✓, les substitucions ✓ i les modulacions ✓ — amb exercicis i solucions amagades ✓
🎨 Bloc B · Reharmonització (3 lliçons)
Els sis recursos ✓, reharmonitzar un tema sencer ✓ i els voicings de guitarra ✓ — amb solucions ✓
🌌 Bloc C · El segle XX (3 lliçons)
Els modes ben entesos ✓, el negative harmony ✓ i els camps harmònics / politonalitat ✓
🎼 Bloc D · Composició (2 lliçons)
La forma de 8 compassos ✓ i l'AABA de 32 ✓ — amb els criteris de correcció ✓
📋 El quadern dels 20 estàndards
Els 20 temes del teu mapa amb la progressió real: fas l'anàlisi i prems «Mostra els graus» per corregir-te sol ✓✓ (no cal escriure res ✓)
🎯 Test de nivell
15 preguntes + 3 exercicis. Si hi tornes un dia, et dirà si has pujat ✓

Com funciona la correcció (sense escriure) ✓

El que m'has de passar ✓: un àudio (o un vídeo curtet) amb el que has fet ✓ — o, si prefereixes, em dius que t'ho pregunti ✓ i t'ho pregunto jo ✓✓.

El que faré jo ✓: escoltar-ho ✓, dir-te què està bé i què no ✓ (amb el perquè ✓), i proposar-te el següent pas ✓✓. I si em passes una anàlisi, la comparem amb la meva ✓.

L'ordre recomanat

  • A ✓ → B ✓ → C ✓ → D ✓ — un bloc no es tanca fins que el seu examen passa per mi ✓
  • L'examen de A i B ✓: 10 anàlisis del quadern ✓
  • L'examen de C ✓: una composició de 8 compassos ✓
  • L'examen de D ✓: una AABA de 32 ✓
